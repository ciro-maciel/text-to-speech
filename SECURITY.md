# Security

Text to Speech copies the selection from other apps through the Accessibility permission, touches the clipboard, and sends text to a server when the internet voice is on. A bug in any of these can expose what someone was reading, so please report it privately.

**How:** open a [private security advisory](https://github.com/ciro-maciel/text-to-speech/security/advisories/new) on this repository. Please don't open a public issue for it.

**What helps:** the macOS version, the app version (menu bar icon, then the settings window), the steps, and what was exposed or sent where.

You will get an answer within a week. Once a fix ships, the advisory is published with credit to you, unless you'd rather stay anonymous.

Supported: the latest release only.
